# 发布与更新

Liteshot 只有一条分发渠道：**Mac App Store**。GitHub 仓库只托管源码，不发布编译好的安装包，也不打二进制版本标签。

## 发版

1. 改 `project.yml` 里的 `MARKETING_VERSION`，同步 `CHANGELOG.md`
2. `xcodegen generate`
3. 归档并上传：

```bash
xcodebuild archive \
  -project Liteshot.xcodeproj -scheme Liteshot \
  -destination 'generic/platform=macOS' \
  -archivePath build/Liteshot.xcarchive \
  -allowProvisioningUpdates DEVELOPMENT_TEAM=BCRZR3P4AP

xcodebuild -exportArchive \
  -archivePath build/Liteshot.xcarchive \
  -exportOptionsPlist /tmp/upload.plist \
  -exportPath dist-upload -allowProvisioningUpdates
```

其中 `upload.plist` 用 `destination = upload`、`method = app-store-connect`，直接走 Apples 的上传通道。

4. 在 App Store Connect 补齐版本信息、截图，提交审核
5. 审核通过后由 App Store 分发

## 更新

应用内没有更新器（App Store 不允许 app 自行下载安装可执行代码），更新全部由 App Store 推送。

## CI

- `.github/workflows/build.yml`：每次 push 编译 + 跑自检，只验证代码能构建，不产出任何分发包
- `.github/workflows/pages.yml`：部署 `site/` 到 GitHub Pages

## 签名

- 分发证书：`Apple Distribution`（Xcode 云托管，私钥在苹果服务器，本机钥匙串里看不到）
- 团队：`BCRZR3P4AP`
- 沙盒与权限写在 `Resources/Liteshot.entitlements`；`com.apple.security.files.pictures.read-write` 在 macOS 上不被支持，已移除

## 备份渠道（不再使用）

仓库曾经发布 ad-hoc 签名的 zip、并通过 `release.yml` 自动化，现已全部移除：
工作流删除，历史 Release 与 `v0.3.x` 标签清理，站点与 README 的下载入口改为 App Store。
