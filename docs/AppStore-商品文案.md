
**描述**
```
Liteshot 是一个菜单栏常驻的 macOS 截图工具，把「框选 → 标注 → 复制/保存」放进同一个覆盖层：拖出区域后工具条直接出现在选区旁，标注直接画在选区上，不会再弹出第二个编辑器窗口。

【截图】
· 区域、窗口、全屏三种入口，拖拽框选或点窗口即截
· 放大镜、取色、边界吸附、方向键微调
· 顶部悬浮模式条：全屏、滚动、跨屏、延迟、上次区域、OCR、二维码、历史

【标注】
· 矩形、椭圆、箭头、画笔、高亮、马赛克、序号、文字
· 6 色色板、撤销/重做，选中元素可移动缩放
· Enter / 双击 / ⌘C 复制退出，⌘S 保存退出

【滚动截图】
· 竖向、横向、全景（横竖同时）三种方向
· 滚动前可改方向，HUD 实时预览，滚动过快会提示可能漏内容

【识别】
· OCR 文字识别使用 macOS 内置 Vision，全部在本机完成，不上传任何内容
· 二维码 / 条形码识别，结果窗口支持上一条/下一条

【输出与效率】
· PNG / JPEG、自动保存、复制到剪贴板、文件名模板
· 圆角、阴影、透明背景、Retina 1x 导出
· 贴图、截图历史（最多 50 张）、全局快捷键自定义
· 中英双语、菜单栏常驻、不占 Dock

【关于隐私】
Liteshot 不联网、不包含任何分析或广告 SDK、不收集任何数据。截图和识别全部在本机处理，只保存在你选择的本地目录。截图需要「屏幕录制」权限，首次使用时应用会先说明用途，再由你决定是否授权。
```

## English

**Name**
```
Liteshot
```

**Subtitle**
```
Menu bar screenshot & markup
```

**Promotional text**
```
Select, annotate, copy — all in one overlay. Scrolling capture, OCR, color picker and pins, native Swift, lives in the menu bar.
```

**Keywords**
```
screenshot,capture,annotate,scrolling capture,OCR,pin,menu bar,color picker,QR code,screen recorder
```

**Description**
```
Liteshot is a menu bar screenshot tool for macOS that keeps the whole flow — select, annotate, copy or save — inside a single overlay. Drag out a region and the toolbar appears right next to it; annotations are drawn directly on the selection, with no second editor window.

CAPTURE
· Region, window and full screen in one entry point
· Magnifier, color picker, edge snapping, arrow-key nudging
· Floating mode bar: full screen, scrolling, cross-display, delay, last area, OCR, QR code, history

ANNOTATE
· Rectangle, ellipse, arrow, pen, highlight, mosaic, counter, text
· Six-color palette, undo/redo, move and resize any element
· Enter / double-click / ⌘C to copy and exit, ⌘S to save and exit

SCROLLING CAPTURE
· Vertical, horizontal and panorama (both axes)
· Change direction before scrolling, live HUD preview, warning when scrolling too fast

RECOGNITION
· OCR runs on-device with Apple's Vision framework — nothing is uploaded
· QR code and barcode detection with previous/next navigation

OUTPUT & SHORTCUTS
· PNG / JPEG, auto-save, copy to clipboard, filename templates
· Rounded corners, shadow, transparency, Retina 1x export
· Pins, capture history (up to 50), customizable global hotkeys
· English and Simplified Chinese, menu bar only, no Dock icon

PRIVACY
Liteshot makes no network requests, ships no analytics or ad SDKs, and collects no data. Screenshots and OCR are processed entirely on your Mac and saved only to the folder you choose. Screen Recording permission is required for capture; the app explains why before the system prompt appears.
```
