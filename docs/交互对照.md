# 交互对照

对照对象：本机 Longshot 1.5.3 的实际菜单、覆盖层与偏好设置。
目标不是逐像素复制，而是让截图主流程的操作顺序、反馈和默认行为一致。

## 1. 截图主流程

| 环节 | Longshot | Liteshot 现状 |
|---|---|---|
| 入口 | 一个截图入口，区域/窗口/全屏自适应 | 菜单「开始截图」⌃⌘A，同一覆盖层自适应 |
| 窗口选择 | 悬停高亮窗口，点击截取 | 悬停高亮 + 窗口标题，点击截取 |
| 多窗口 | Shift 多选 | Shift 多选，编号边框，Enter 合成 |
| 区域选择 | 拖拽框选，带尺寸与辅助 | 拖拽框选，尺寸标签、放大镜、取色、吸附 |
| 全屏 | 独立入口 | 点空白处或按 F |
| 浮动工具条 | 标注/复制/保存/滚动/OCR/贴图等 | 图标工具条：标注/复制/保存/滚动/OCR/钉图，支持 1–6 |
| 滚动截图 | 覆盖层里选方向，拖区域或点窗口 | 覆盖层方向按钮 + 拖区域/点窗口；HUD 可改方向、带缩略图 |

## 3. 偏好设置映射

Longshot 页签：通用 / 截图 / 贴图 / OCR / 测量 / 快捷键 / 专业版 / 关于。

| 页签 | Liteshot 对应 | 状态 |
|---|---|---|
| 通用 | 设置 → 语言；启动项暂无 | 部分 |
| 截图 | 保存、文件名、导出、快捷键、截图、选区外观 | 大部分 |
| 贴图 | 钉图行为 | 基础 |
| OCR | 保留换行、静默 OCR、显示窗口 | 部分 |
| 测量 | 不做（截图域外） | 不实现 |
| 快捷键 | 开始截图一个组合键 | 基础 |
| 专业版 | 不做 | 不实现 |
| 关于 | 关于页 | 有 |

截图页已对齐：PNG/JPEG、自动保存、复制、Finder 显示、文件名模板、Retina 1x、圆角、阴影大小/不透明度/颜色、透明背景、遮罩颜色/透明度、高亮颜色、尺寸标签位置、比例锁定、延迟、光标、放大镜、边界吸附。
