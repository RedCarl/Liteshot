# 口语版：Liteshot 是干嘛的

## 一句话

就是个截屏小工具。装好之后住在菜单栏，按一下快捷键，框一块屏幕，画两笔，直接粘走。

## 谁会用

- **写代码的**：截报错、截日志、截配置，圈出重点发到 Issue 里
- **做产品的**：需求文档、评审、周报里要配图，还得标个号、加个箭头
- **上班天天发截图的**：客服、行政、财务，发流程、发单据
- **老师学生**：网课讲题、抄课件、抄代码

## 能干啥（大白话）

**抓图**
框一块、点个窗口、或者整个屏幕。多显示器也能跨着框。想慢点截就开 5 秒延迟，够你切窗口。

**截长图**
一页放不下？开着滚动截图往下滚，它自动拼成一张长图。横着滚也行，表格宽也能接。

**标重点**
画方框、画箭头、涂两笔、打马赛克（遮掉密码和 token）、加编号、写字。都有。

**抄图里的字**
图上的文字可以直接识别成能复制的文字，二维码也能读出来。**全在本机跑，不联网，图片不会上传。**

**把图钉在屏幕上**
截下来钉住，浮在最上层。对着填表、抄参数的时候不用来回切窗口。

**存得整齐**
存哪、叫什么名、什么格式，都能自己定。想加圆角阴影也行。

**回头找**
最近 50 张截图都在历史里，随用随取。

## 跟别的不一样在哪

- 别的工具截完图会弹一个编辑器窗口，让你在里面标。Liteshot 是**直接在选区上标**，标完回车就是成品。
- 它**不联网**。没有账号、没有云同步、没有广告和统计。截图只存在你自己电脑上。
- 很小，1.6 MB。

## 谁用不上

要录屏做视频的、需要团队共享和云图库的、用 Windows 的——这个不是给你们的。

## 一句话卖点

按一下，框一块，画两笔，粘走。就这样。
