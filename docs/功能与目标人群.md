# Liteshot 功能与目标人群

给 App Store 文案、官网、宣发物料用的一份事实底稿。所有功能点都能在代码里找到对应实现，不写没做的东西。

---

## 一句话定位

**Liteshot 是一个菜单栏常驻的 macOS 截图工具，把「框选 → 标注 → 复制/保存」压进同一个覆盖层。**

对比参照：系统自带的 `⌘⇧4` 只能框选，标注要去「预览」里二次加工；其他截图工具大多会弹出独立的编辑器窗口。Liteshot 的做法是——工具条直接出现在选区旁边，标注直接画在选区上，标完按 Enter 就是剪贴板里的最终图。

---

## 目标人群

按「用截图的频率」和「对截图的要求」两个维度，主力人群是前两类。

### 1. 开发者 / 技术支持（高频、要求精确）

- 写 Issue、PR、技术文档时要贴图
- 需要把报错、日志、配置**重点框出来**，不然对方看不懂
- 经常要截**长的**东西：终端输出、日志文件、CI 页面、一整个网页
- 在意：快捷键顺手、不打断思路、图片直接进剪贴板、不联网

对应功能：区域/窗口截图、矩形与箭头标注、马赛克（糊掉 token、内网地址）、滚动截图（竖向抓长日志、横向抓宽表格）、⌘C 直接复制、全局快捷键自定义。

### 2. 产品经理 / 设计师 / 运营（高频、要求好看）

- 做需求文档、评审材料、周报，图要能直接放进文档
- 要标注：编号、箭头、高亮、文字说明
- 在意：圆角、阴影、Retina 清晰度、导出格式、批量命名

对应功能：序号标注、高亮、文字、圆角/阴影/透明背景导出、PNG/JPEG 切换、文件名模板（`Liteshot-{yyyy}{MM}{dd}-{seq}`）、截图历史（最近 50 张，随时翻回来复用）。

### 3. 教师 / 学生 / 远程办公（中频）

- 网课、远程协助时要截屏讲解
- OCR 抄课件、抄代码、抄文档里的文字

对应功能：OCR 文字识别（macOS Vision，本机跑，不上传）、二维码/条码识别、贴图（钉在屏幕上对照着看，不挡操作）、延迟截图（倒计时 5 秒，够时间切换窗口）。

### 4. 客服 / 行政 / 财务（中频，非技术）

- 把流程截图发给同事或客户
- 文件要能找得到、名字要规整

对应功能：一键保存到指定目录、文件名模板、保存后在 Finder 中显示、历史记录可回溯。

### 不面向谁

- 需要**录屏/视频剪辑**的人（Liteshot 不做视频）
- 需要**团队协作、云端图库、链接分享**的人（应用完全不联网，没有账号体系）
- Windows / Linux 用户（原生 macOS 应用，最低 macOS 14）

## 功能清单（按使用场景组织）

### 场景 A：抓到想要的画面

| 功能 | 细节 |
|---|---|
| 区域截图 | 拖拽框选，带放大镜、取色、边界吸附、Shift 正方形、方向键微调 |
| 窗口截图 | 鼠标悬停高亮窗口，点一下直接截，自动去背景 |
| 全屏截图 | 点空白处或按 F |
| 跨屏截图 | 多显示器跨屏选区 |
| 延迟截图 | 5 秒倒计时，够时间切到目标窗口 |
| 上次区域 | 记住上一次选中的区域，重截同一块 |

### 场景 B：把重点标出来

矩形、椭圆、箭头、画笔、高亮、马赛克、序号、文字，8 种工具；6 色色板；撤销/重做；选中元素可移动、缩放；描边粗细可调。标注直接画在选区上，没有第二个窗口。

### 场景 C：一次截完长的东西

滚动截图分三种方向：竖向（网页、聊天记录、日志）、横向（宽表格、甘特图）、全景（横竖同时）。滚动前可改方向，HUD 实时显示已拼接的缩略图；滚太快会提示可能漏内容。

### 场景 D：图里的字要能复制

- **OCR**：macOS 内置 Vision 框架，**本机识别，不上传**。结果窗口支持「上一个/下一个」，保留最近 20 条
- **二维码 / 条形码**：直接识别出内容

### 场景 E：图要能留在屏幕上对照

贴图（Pin）：把截图钉在最上层，缩放、透明度可调，可整体隐藏/显示。对照着填表、抄参数时不用反复切窗口。

### 场景 F：存得整齐、找得回来

- 保存目录可自定义，格式 PNG/JPEG，JPEG 质量可调
- 文件名模板：`{yyyy}{MM}{dd}{HH}{mm}{ss}{seq}` 等占位符
- 导出选项：圆角、阴影、透明背景、Retina 缩小到 1x
- 截图历史：最近 50 张，可复制、打开、在 Finder 中显示

### 场景 G：不打扰

菜单栏常驻（`LSUIElement`），不占 Dock；全局快捷键可自定义；中英双语，跟随系统或手动切换。

## 差异化对照

| | 系统自带截图 | 典型第三方截图工具 | Liteshot |
|---|---|---|---|
| 标注位置 | 需进「预览」二次编辑 | 常弹独立编辑器 | 直接画在选区上 |
| 滚动截图 | 无 | 部分有 | 竖向 / 横向 / 全景 |
| OCR | 有（实况文本） | 部分要联网 | 本机 Vision，离线 |
| 隐私 | 本机 | 常见统计 SDK | 完全不联网、无 SDK、无账号 |
| 体积 | — | 常见几十 MB | 安装包约 1.6 MB |

---

## 隐私立场（可直接用于文案）

Liteshot 不联网：没有账号、没有云同步、没有统计和广告 SDK，不上传任何截图。OCR 用本机 Vision 完成。截图只写入你自己选的本地文件夹。

对隐私敏感的场景（法务、财务、医疗、内网环境），这一条往往是决定性的。
