第一次截图没有反应？

Liteshot 需要「屏幕录制」权限。首次启动时应用会先弹出自己的说明页，点「打开设置」后，在 系统设置 → 隐私与安全性 → 屏幕与系统音频录制 里勾选 Liteshot。授权后需要退出并重新打开应用一次。

截图保存到哪里了？

默认保存到 ~/Downloads/Liteshot（或 ~/Pictures/Liteshot，取决于系统是否放行）。可以在 设置 → 保存 里点「选择…」改成任意文件夹，重启后依然有效。

快捷键是什么？

  • 开始截图：⌃⌘A
  • 复制并退出：Enter / 双击 / ⌘C
  • 保存并退出：⌘S
  • 取消：Esc
  • 撤销 / 重做：⌘Z / ⇧⌘Z

全部快捷键都能在「设置 → 快捷键」里改。

为什么菜单栏没有图标？

Liteshot 是菜单栏应用（不占 Dock）。启动后请查看屏幕右上角菜单栏，图标是一把剪刀。如果菜单栏图标太多被折叠了，先隐藏一些其他图标。

滚动截图拼接有错位？

滚动速度过快时拼接会失准，HUD 会给出提示。建议每次滚动幅度小一些、稍作停顿再继续。

怎么切换语言？

设置 → 语言 / Language → 界面语言，可选「跟随系统」「简体中文」「English」。

数据会被上传吗？

不会。Liteshot 不联网，OCR 使用本机 Vision 框架。详见 隐私政策。
