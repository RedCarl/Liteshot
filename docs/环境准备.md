## 日常命令

```bash
# 生成/更新工程（改了 project.yml 或增删文件后）
xcodegen generate

# 打开工程
open Liteshot.xcodeproj

# 命令行构建
xcodebuild -project Liteshot.xcodeproj -scheme Liteshot \
  -configuration Debug -destination 'platform=macOS,arch=arm64' build

# 构建产物
open ~/Library/Developer/Xcode/DerivedData/Liteshot-*/Build/Products/Debug/Liteshot.app
```

- Debug 产物里有 `Liteshot.debug.dylib`，是 Xcode 的 debug dylib 机制，正常。
- `.xcodeproj` 与 `Resources/Info.plist` 都是 XcodeGen 生成的，已进 `.gitignore`。
