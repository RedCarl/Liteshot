## 2. 上传构建

两种方式，任选：

**方式 A（推荐，图形界面）**：打开 Transporter App → 用 Apple ID 登录 → 把 `dist/Liteshot.pkg` 拖进去 → 交付。

**方式 B（命令行）**：

```bash
xcrun altool --upload-app -f dist/Liteshot.pkg -t macos \
  --apiKey <你的 Key ID> --apiIssuer <你的 Issuer ID>
```

需要先生成 App Store Connect API 密钥（用户和访问 → 密钥 → App Store Connect API）。

上传后等几分钟，在 App Store Connect 的「TestFlight / 构建版本」里能看到 1.0.0 (1)。

## 7. 审核备注（英文，直接粘）

```
Liteshot is a screenshot and annotation tool for macOS. It runs as a menu bar app
(LSUIElement), so there is no Dock icon — after launch, click the scissors icon in
the menu bar.

Screen Recording permission is required for its only core function (screen capture).
The app does not request it automatically: it shows its own guidance window first,
and the system prompt only appears after the user taps "Open Settings".

The app is fully offline: it makes no network requests, contains no analytics or ad
SDKs, and collects no user data. OCR runs on-device with Vision; images never leave
the Mac.

ICP filing number for China mainland: 鄂ICP备2024059854号-3A

Test steps: 1) launch, 2) menu bar → Start Capture (⌃⌘A), 3) drag a region,
4) press Enter to copy.
```
